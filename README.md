# Robot Games

Two standalone Progressive Web Apps share this repository:

- [FightBots](https://ahlgrenpersonal.github.io/fightbots/): build two robots and watch an arena battle.
- [Bot Adventure](https://ahlgrenpersonal.github.io/fightbots/bot-adventure/): explore, collect parts, build equipment, and restore five relays.

On iPhone, open either game in Safari and choose Share > Add to Home Screen. Each game has its own installation scope, offline cache, and save behavior.

The `bot-adventure/` directory contains only the adventure's runtime files, icons, and license. Development tools, test data, personal notes, and local instructions are excluded.
